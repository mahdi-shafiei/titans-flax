# Optimization Utilities

Performance optimization utilities for Titans models including memory optimization, gradient checkpointing, and quantization.

::: titans.optimization_utilities

## Key Classes

- **MemoryOptimizer** - Memory usage optimization and analysis
- **PerformanceProfiler** - Performance profiling and analysis
- **GradientCheckpointing** - Gradient checkpointing utilities
- **InferenceOptimizer** - Inference-specific optimizations
- **QuantizationUtils** - Model quantization utilities

## Features

- Memory usage estimation and optimization
- Performance profiling and analysis
- Gradient checkpointing for memory efficiency
- Mixed precision training support
- Model quantization for deployment
