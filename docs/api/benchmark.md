# Benchmarking

Full benchmarking suite for Titans models including performance analysis and comparison tools.

::: titans.benchmark
    options:
      show_root_heading: true
      show_source: true
      heading_level: 2

## Key Classes

- **TitansBenchmark** - Full benchmarking suite
- **BenchmarkResult** - Individual benchmark results container
- **PerformanceMetrics** - Performance metrics collection and analysis

## Features

- Multi-variant performance comparison
- Memory usage analysis
- Scaling behavior studies
- Throughput and latency measurements
- Visualization and reporting tools
