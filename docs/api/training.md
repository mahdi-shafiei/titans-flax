# Training

Training utilities and classes for Titans models including advanced training loops, checkpointing, and metrics.

::: titans.training

## Key Classes

- **TitansTrainer** - Advanced trainer with checkpointing and memory adaptation
- **TrainingMetrics** - Training metrics container and tracking
- **LearningRateScheduler** - Learning rate scheduling utilities

## Features

- Automatic memory adaptation during training
- Checkpointing and model serialization
- Advanced training metrics and logging
- Support for different optimization strategies
