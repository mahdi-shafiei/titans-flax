# Serialization

Serialization and checkpointing utilities for Titans models including model persistence and memory state management.

::: titans.serialization
    options:
      show_root_heading: true
      show_source: true
      heading_level: 2

## Key Classes

- **TitansCheckpoint** - Checkpoint management for models and memory states
- **ModelExporter** - Model export utilities for deployment
- **MemoryStateManager** - Memory state persistence and loading

## Features

- Complete model checkpointing
- Memory state serialization
- Cross-platform compatibility
- Efficient storage formats
- Version compatibility checking
