# Architecture Variants

The four Titans architecture variants with different memory integration strategies.

## Variants Overview

- **TitansMAC** - Memory as Context: Best for very long sequences (2M+ tokens)
- **TitansMAG** - Memory as Gate: Balanced efficiency and effectiveness
- **TitansMAL** - Memory as Layer: Fast training and simple architecture
- **TitansLMM** - Long-term Memory Module: Pure memory without attention
